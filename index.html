Questions, answered.

What does WebSnap capture?

Any public web page, either the full scrolling page or just the visible viewport, saved as a PNG or JPEG.

Do I need to install a browser?

No. Chromium is bundled in the app. Edge or Chrome are used only as a backup.

Where do my screenshots go?

To the folder you choose with Browse. The default is your Pictures folder, and nothing gets uploaded anywhere.

Why are some images missing in other tools?

Many sites load images only when you scroll to them. Auto-scroll fixes that, so everything is there before the capture.

Which platforms are supported?

The app is packaged as a Windows executable. It also opens files and folders natively on macOS and Linux when run from source.
